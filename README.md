\# WhisperApp v2.1



A Windows desktop app that uses OpenAI Whisper and ffmpeg to transcribe audio files to text.

Download the Windows build here: 
[WhisperApp v2.1 Windows ZIP](https://drive.google.com/file/d/1Kr06ZNmFblv06vzwvKk5DcMwKAr8XTwV/view?usp=sharing)

After downloading:
1. Extract the ZIP to a folder
2. Make sure 'WhisperApp_v2.1.exe' and 'ffmpeg.exe' stay in the same folder
3. Double-click 'WhisperApp_v2.1.exe' to run the app

This folder contains the Python source code (`transcriber\_app.py`) and the PyInstaller spec (`WhisperApp\_v2.1.spec`) used to build the app.
